# 印章按钮本地试验

使用内置 image_gen 生成，文字仍由页面渲染。

- public/assets/stamp-button-normal-v1.png / .webp：透明空心印章。
- public/assets/stamp-button-pressed-v1.png / .webp：实心印章；源图为 RGB，页面 SVG 滤镜移除浅色背景并保留输入透明度。
- 正常、按下两态使用不同图片；状态章复用空心印章。

生成提示：空心为日式医院文件上暗朱红双线橡皮章，空白中心，缺墨与纸纤维纹理，无文字、阴影或背景。按下态保留边框构图，内部填充暗朱红墨迹，轻微缺墨，无文字。按下图外边距不同，页面按中心放大适配。

验证：TypeScript 检查；本地主界面截图；点击后状态变为已接班并进入游戏；强制显示按下态检查滤镜黑边，修复后移除临时样式。
