# 夜班档案 / NIGHT SHIFT · 0.4

面向 TikTok 游戏直播的像素恐怖搜寻原型。当前入口为逐关解锁模式：找专用钥匙、开门开箱、收齐 3 个保险丝、在 EXIT 按 E 逃生。没有密码谜题或额外配电箱操作。主界面按关卡选择，初始仅解锁第一关；通关解锁下一关，已通关可重玩。进度保存在当前浏览器 localStorage，刷新保留；清除站点数据会重置解锁进度。旧双夜剧情代码保留在 `src/scene.ts`，当前入口使用 `src/endless.ts`，旧剧情异常不在无限模式里启用。

## 运行

```sh
npm install
npm run dev
npm run build
npm test
```

打开 Vite 输出的地址；当前工作环境为 http://localhost:5174。标题“进入值班台”或“开始夜班”点击后启用本地配乐，支持静音与音量。首次播放需要浏览器用户手势。

## 规则

- WASD / 方向键移动；E 拾取钥匙、开关门、开箱和逃生；Shift 疾跑。
- 每图 3 个箱子：无锁箱提供红牌病房钥匙；地上的铜钥匙开启铜锁箱并取得蓝牌封箱钥匙；蓝牌钥匙开启房内最后一个箱子。每箱仍有 1 个保险丝。三种钥匙各用于对应的锁，开锁后消耗；已解锁的房门可以反复开关，无需再次消耗。
- F 使用闪光器：击退 190 像素内的怪物并定身 4 秒。R 留下 8 秒诱饵，Q 使用绷带恢复 40 生命。
- 每轮重置生命、电量以及 3 个闪光器、3 个诱饵、2 份绷带。怪物出现前预警 3 秒；接触伤害 12，间隔 1.8 秒。听声者和畏光者能穿墙，巡逻者受墙、家具和关闭的门阻挡。
- 角色脚边独立照明。环境灯有暖黄、冷蓝、暗红和绿青色；观众熄灯不会关闭手电或角色照明。
- 三个地图模板：病房分室、仓库货架走道、机房错位隔墙。每张图有两组物资配置，按轮次轮换。目前是三模板/六配置无限循环，不是无限独特地图。每轮一种威胁，速度与出现间隔增长有上限。没有时间耗尽淘汰。
- 三种行为：听声者追踪疾跑、开箱和开关门的声音，记忆消退后停下；畏光者被手电正面照射时减速，闪光额外定身 2 秒；巡逻者寻路追击，可用关门阻挡。三者目前共用角色图集，以色调区分。
- 每轮一种明确提示的事件：静默巡查延长追逐间隔、补给充足多 1 个闪光器、供电检修每 30 秒熄灭环境灯 4 秒。事件不封锁必经路线。
- 通关不再提供强化奖励；闪光基础定身 4 秒、诱饵 8 秒、每关基础绷带 1 个。
- 通关显示独立结算，可继续下一关或返回选关；死亡不解锁新关卡，可重试本关。结算后可直接继续，已解锁关卡可随时重玩。

## 观众事件

当前 4 增益（reveal / supply / repel / sanctuary）、4 减益（blackout / ghost / drain / alarm），共享目录为 `game/commands.json`。旧 battery / lure 接口已移除，玩家 R 诱饵保留。

| command | 效果 |
| --- | --- |
| reveal | 12 秒标出钥匙和未开启箱子 |
| supply | 闪光器 +1（上限 5）、绷带 +1（上限 6） |
| repel | 击退追逐者，基础定身 4 秒，畏光者额外 2 秒 |
| alarm | 减益：6 秒暴露位置，R 诱饵可转移，持续期间不叠加 |
| blackout | 环境灯熄灭 4 秒，叠加上限 7 秒，手电保留 |
| ghost | 3 秒预警后追逐 18 秒；已存在则延时，剩余上限 20 秒 |
| drain | 减益：8 秒最多额外耗电 16%，持续期间不叠加 |
| sanctuary | 至少 8 秒免伤保护 |

```sh
curl -X POST http://localhost:5174/api/webhook \
  -H 'Content-Type: application/json' \
  -d '{"id":"gift-001","command":"reveal","viewer":"夜行者"}'
```

这是 Vite 开发服务器的 POST → SSE 内部协议，TT 协议尚未确定。ID 幂等与 700ms 全局限流；可通过服务端 `WEBHOOK_TOKEN` 启用 Bearer 校验。暂停、标题、结算期间收到的事件不作用于游戏。当前向所有打开页面广播，仅适合单直播间本地开发；静态 `dist` 和 preview 不提供 webhook。

## 验证

```sh
npm run test:browser
npm run test:browser:night2
```

需要开发服务器与本机 Chrome。默认地址 5174，可用 `BASE_URL` 覆盖。两组测试分别从第 1 关和带已解锁存档的第 2 关开始，使用真实键盘完成三轮搜寻，检查箱子、房内关门、结算及无奖励选择的连续过关。第一组还验证 webhook、新观众指令、闪光反制、暂停、默认音乐及手机宽度。测试还覆盖初始锁关、逐关解锁、刷新保留和重玩选择。单元检查覆盖全部六套物资配置的可达性、巡逻者锁门隔离与开门寻路、照射方向判断。

## 技术与范围

TypeScript + Phaser + Vite；沿用已有像素 PNG 与本地 ElevenLabs 配乐，未增加外部音频调用。三张地图均已迁入 LDtk，通过 `game/levels.json` 注册并加载独立声光事件。镜头、灯光画布和寻路读取地图尺寸与标记；Aseprite 尚未提供原生工程。制作说明见 `game/README.md`。历史方案见 `docs/iteration-03.md`；已加入怪物行为差异、单轮事件；下一步重点是可选搜寻分岔和更有起伏的事件节奏。长期耐玩性仍需真人试玩验证。

场景新增低亮度电话指示灯、旧 CRT、供灯、纸符和朝向变化的小人偶；地面增加成组污斑、潮湿边缘、脚印、拖痕与纸屑。门以门框、门牌、门槛和靠近描边区别于墙体。新增装饰不改变通行碰撞。

像素渲染第一阶段：内部 640×384，桌面整数放大，旧世界坐标通过 1 倍相机缩放保留。素材规格见 `game/assets/manifest.json`，迁移范围及小窗口例外见 `docs/architecture/pixel-contract.md`。现有 PNG 加载时采样为固定大小帧，原始图片不变。

数据化第一阶段已接入病房：LDtk 保存后由 Vite 校验并生成运行数据；`npm run content:check` 可单独验证。事件运行器支持游戏时间等待、声音、CRT 光源和提示，暂停及换关不会遗留定时回调。

玩家界面样式集中在 `src/game-ui.css`：选关、HUD、结算及弹窗使用统一像素边框，直播控制为不改变游戏尺寸的浮动面板，Escape 可关闭。中文像素字使用本地 Ark Pixel 12px（2026.07.20），来源与 OFL 许可保存在 `public/fonts/`；无需访问外部字体 CDN。旧开发统计区仍保留内部节点以兼容事件记录，但默认玩家布局不展示。

钥匙与箱子的像素图形独立在 `src/item-art.ts`：钥匙含中空钥匙环、齿和铜牌；箱盖、铰链、铜锁及蓝色封条用于识别类型。只改图形与提示，保持原碰撞和交互范围。

## Roguelike 玩法
第二关起保留 LDtk 原有房间与家具，物资在原搜寻区内小范围随机；额外交互收敛为补给药柜和藏身柜。起始闪光/诱饵/绷带各 1，补给关多 1 闪光。操作及约束见 `docs/roguelike-implementation.md`。`maps/rooms/` 中的实验模块暂不参与随机生成。
