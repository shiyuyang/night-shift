# 夜班档案：从互动原型到生存恐怖

> 本文保留长期规划。最新已实现的美术、碰撞与音频功能以 [0.3 说明](iteration-03.md) 为准。

## 方向

恐怖来自“知道有危险，却无法完全掌握它”。每章先让玩家学会一条生存规则，再用环境和观众事件打乱这条规则。难度增长应增加决策与信息差，而非只加快怪物或延长搜集清单。

视觉统一采用病院旧监控设备：冷灰绿、骨白、少量铁锈红，墙面与 UI 共用锈蚀材质；游戏内采用最近邻像素采样。生成贴图承担表面细节，碰撞、交互与关卡结构仍由确定性的游戏数据决定。

## 0.2：当前已实现

- 生成地砖、锈蚀墙板和走廊封面；实际用于 Phaser 地面、墙体及终端面板。
- 扇形手电和近身视野；射线与墙体/封板相交时截断，无法隔墙看穿整个房间。
- 细长追逐者、环境污迹、弱应急灯与深色遮蔽。
- 开启声音后，合成低频环境音、行走脚步、金属异响和追逐心跳；暂停、结束时静音。
- 第一夜保留入门收集逃生；第二夜可直接选择，增加完整道具和密码流程。
- 第二夜：西南撬棍 → 西北病历 → 南侧密码药柜 → 撬开东侧封板 → 收集保险丝 → 北侧配电箱 → 东侧出口。
- 病历包含三个床位数字，药柜按 03→01→02 顺序输入，每局重新生成数字。查看病历会暂停；操作密码锁时世界继续，输入错误会召唤追逐者。
- 碎玻璃与疾跑增加噪声；噪声过高会在追逐冷却接近结束时提前招敌。漏电电缆每 7 秒通电 2.5 秒。
- 一份绷带恢复 35 生命；两个发条诱饵，各吸引追逐者 7 秒。现有观众礼物继续支持补电与保护，也能熄灯与招敌。

目前第二夜复用第一夜的医院布局。追逐者仍为单一穿墙敌人；病床/柜子是装饰，墙和封板是实体碰撞。声音是程序合成，尚非录制/专业混音素材；不将封面插画视为可探索的三维走廊。

## 下一步：先打磨一章

优先做完整的第二夜纵向样板，再扩展地图数量。

1. 用 Aseprite 做人物、病床、幽灵与门的成套动画，让生成材质和可交互物件有统一像素密度；用 LDtk 管理实体、碰撞、触发区和光源。
2. 将追逐升级为“巡逻 → 怀疑 → 搜索 → 追逐 → 丢失目标”，怪物听到噪声只搜索声源附近，不永久知道玩家位置。加入柜中躲藏与屏息，明确危险预兆。
3. 添加录制的空间脚步、门后敲击、配电箱电流、远处推床声；先营造 10–30 秒的预期，再给事件结果，避免连续惊吓导致麻木。
4. 道具承重与有限快捷栏：撬棍负责门板，绝缘手套负责漏电区，止血绷带负责受伤，发条玩具负责声源诱导。每件道具至少有一处改变路线的用途。
5. 实测无礼物、只有援助、只有捣乱和高频混合事件四种场景；确保单人可通关，礼物能改写路线而不是直接决定输赢。

验收重点：新玩家能理解下一步目标、追逐有反制、谜题答案可由游戏内信息推导、失败原因可被主播与观众理解。可见度不能仅靠降低亮度制造难度。

## 三章递进

| 章节 | 核心规则 | 道具与谜题 | 观众可参与的变化 |
| --- | --- | --- | --- |
| 第一夜：初次值班 | 学会看光、听声、保留电量 | 简单搜集、出口供电 | 补电 / 短熄灯 / 单次追逐 |
| 第二夜：封锁病区 | 噪声与路线选择 | 撬棍、病历排序、漏电、配电箱 | 制造远处敲击、为主播争取安静窗口、送临时保护 |
| 第三夜：地下停尸间（计划） | 电力只能分配给部分区域 | 冷库温度、推床重压开关、继电器联锁 | 投票给哪一区域供电；观众看见局部监控线索，主播负责执行 |

第三夜的主线不依赖真实礼物。无观众时，通过院内终端获得同一条线索；有观众时，分享信息和时机成为直播看点。线索型事件不收费锁死关键答案。

## 互动系统迭代

暂时保留四种核心 webhook 命令，避免 TT 协议未确认前扩大外部契约。新道具和谜题先在客户端验证，后续再将 `noise_at`、`power_zone`、`reveal_clue` 映射到正式服务器事件。

正式事件流要有房间隔离、签名验证、持久化去重、断线恢复，以及事件“收到 / 排队 / 生效 / 取消”回执。恐怖事件设置房间独立冷却与压力预算，不能无限叠怪、连锁熄灯。援助应允许在恐怖冷却期间生效，不让恶作剧流量挤掉救援。
