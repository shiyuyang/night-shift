# NIGHT SHIFT：日本市场优先的日式恐怖修改策划案

日期：2026-09-07  
状态：设计提案，待确认；本文件不表示功能已经实现。  
范围：世界观、六个固定关卡、无限夜班、美术声音、直播互动和本地化。沿用俯视角像素玩法，首版使用现有三张地图，不在本次方案中扩大为六张地图。

## 1. 产品方向

一句话：你受雇看守一所日本地方医院的旧病栋。凌晨 2:17，交班迟迟没有到来，已停用的病房却开始呼叫。

玩家体验从熟悉工作、察觉不对、判断危险，走向搜寻与撤离。观众能够先发现背景异常、提醒主播，并通过现有指令影响局势。探索本身应成立，没有观众指令也能完成全部固定关卡。

日本为首要设计与语言验收市场；所有地区保留同一所日本医院、人物身份、场景标识和故事。菜单、操作、任务、字幕与帮助按语言本地化。首批语言为日语、英语、简体中文，其他语言在该流程验证后追加。

“日本优先”是本次产品选择，尚无用户研究证明当前玩法适合日本市场。需要日本玩家和主播实际试玩验证，不能把日恐题材等同于市场接受度。

## 2. 品牌与世界观

### 名称

- 建议全球展示名暂统一为 **NIGHT SHIFT**，现有英文名可直接沿用；项目内部仍可称“夜班档案”。这不是最终品牌定名，正式对外发布前另做名称可发现性与重名检索。
- 各语言可以使用自己的宣传短句，不作为第二个游戏名称。
- 日文候选：`午前二時十七分。交代の職員は、まだ来ない。`
- 中文候选：`凌晨两点十七分。接班的人，还没有来。`
- 英文候选：`2:17 a.m. Your replacement still hasn't arrived.`

以上日文均为工作稿，进入素材和录音前由日语母语编辑统一审校。

### 场景身份

将当前“圣艾格尼斯医院 / ST. AGNES HOSPITAL”调整为日本地方医院的旧病栋。机构专名暂不编造，关卡与概念稿使用“旧病栋 / 旧病棟”。世界设定为当代，旧楼保留较早时期的内装与设备，避免为了复古而让全世界都停留在某一年。

玩家是受雇巡查旧楼的夜间设施值守员，承担检查门锁、备用物资和供电状态的工作。医院主楼在场景外，旧楼已经停用。异常围绕未完成的交班和一份反复出现的巡查记录展开。

第一篇章解释一个具体问题：为什么每次离开工作区，都会回到同一张值班桌。第六关允许完成一次交班、看到明确结局；无限模式作为“另一份没有结束的记录”单独进入，不取消固定篇章的完成感。

避免用疾病或患者身份直接解释邪恶。怪物呈现为旧楼中的异常身影，病历提供人物经历和事件线索，不把诊断名称当作恐怖标签。

## 3. 六关结构与命名

固定关卡采用“巡查记录 01 + 事件题目 + 地点”；日文界面可用 `巡回記録 01`。地点是稳定名称，题目描述该次经历，不随语言改变地图身份。

| 记录 | 日文题目（工作稿） | 中文 / 英文题目（工作稿） | 地点 | 本关设计与区别 |
| --- | --- | --- | --- | --- |
| 01 | 初めての夜勤 | 第一次夜班 / First Night Shift | 旧病栋 | 固定物资与安全教学；离开空病房后，身后呼叫灯亮起；建立正常空间印象 |
| 02 | 棚の向こう | 货架另一侧 / Beyond the Shelves | 药品仓库 | 用货架遮挡与可定位声音引导判断；学习切断视线；只安排一种主威胁 |
| 03 | 停電 | 停电 / Power Outage | 地下机房 | 介绍照明取舍；首次哭泣身影放在有明确绕路的位置；保留现有反制 |
| 04 | 誰もいない病室 | 无人的病房 / An Empty Room | 旧病栋 | 返回熟悉地点，呼叫来自原先空置房间；设计一处可验证的新通路，改变搜寻顺序 |
| 05 | 返却物 | 归还物品 / Returned Items | 药品仓库 | 可选补给与交班线索放在较危险支路；主播决定是否多搜；主线不要求收集线索 |
| 06 | 引き継ぎ | 交班 / Handover | 地下机房 | 综合既有规则，完成最后撤离；结尾回值班桌签退，首次出现不同于 2:17 的时间 |

后半三关至少各包含：一项路线或目标顺序变化、一段专属环境事件、一份推进交班故事的线索。只有物资随机和数值增加，不算完成新关卡制作。

三枚保险丝、钥匙与箱子、八秒供电、闪光/诱饵/治疗作为首轮可玩基线保留。修订后的叙事说明它们服务于本区撤离供电；搜集齐后自动供电仍是游戏简化，不额外增加配电箱谜题。若试玩认为六关反复找保险丝明显疲劳，再单独评估一种替代目标，避免同时改题材和主循环后难以定位问题。

目标首次成功通关每关 3–5 分钟，六关合计 18–30 分钟，不含重试。该时长是设计目标，不是现有实测结果。

## 4. 日恐表现：从环境到实际危险

一关的参考节奏：正常巡查 → 一次不明确异常 → 可辨认的危险预告 → 搜寻或绕行 → 最后撤离 → 安静结算。允许部分轮次没有强烈惊吓，保持不确定性。

| 层次 | 示例 | 规则 |
| --- | --- | --- |
| 环境异常 | 空床呼叫灯、广播读到一半停止、刚经过的轮椅转向 | 不造成伤害，不新增待办图标；观众可以先看见 |
| 危险预告 | 货架后有拖行声、哭声在照射后停止、拐角露出衣摆 | 与后续威胁一致；玩家掌握后能够判断 |
| 实际遭遇 | 追逐、扑击、撤离时供电中断 | 保留碰撞、预警、脱战及反制；不因剧情暗改规则 |

优先制作 12 个环境事件：病区、仓库、机房各 4 个。固定关卡安排其中的教学与剧情版本，无限模式抽取兼容版本。每个事件只做一个清楚的变化，配置发生区域、前置状态、重复冷却、声音和是否占用危险时段。

不添加“发现异常就回头”的通关判断；当前核心仍是搜寻撤离。也不让走廊呼唤之类的气氛文字伪装成尚未实现的致死规则。需要玩家操作遵守的规则，必须在机制上真实存在。

## 5. 美术与声音修改

### 保留与替换

保留三图大部分墙体、家具碰撞、俯视角、像素尺寸和已有灯光系统。优先替换玩家最常见到的识别物：值班桌、地图牌、病室门牌、呼叫设备、药箱标签、公告栏与出口导引。

| 项目 | 修改方向 | 首版工作边界 |
| --- | --- | --- |
| 值班室与选关 | 日文巡查簿、交班夹页、盖章、旧楼平面图 | 改名称、纸面版式、关键桌面物；保留现有选关功能 |
| 旧病栋 | 浅色墙裙、床帘、呼叫面板、日文房牌 | 先做一个代表区域，再扩展到全图 |
| 药品仓库 | 日文库存标签、退回箱、金属推车 | 用货架节奏和遮挡体现身份，不另造大套家具 |
| 地下机房 | 日文设备牌、管线、检修记录、应急灯 | 沿用隔墙与设备轮廓，减少无来源彩光 |
| 装饰 | 日历、注意事项、轮椅、个人遗留物 | 普通医院首先可信；纸符、人偶仅在有剧情来源时出现 |
| 色彩 | 褪色米白、灰绿、旧金属；局部冷白与暖色值班灯 | 红色用于危险变化；避免所有房间长期暗红 |

减少常驻 CRT 和扫描线的存在感，优先用于监视器、回放或菜单；玩家直接观察的场景保持物体清楚。关灯仍能识别脚边与近处交互。

### 怪物

首版维持现有普通威胁类型和哭泣身影，不因为换风格新增第三套复杂遭遇系统。调整步态、剪影、材质与声音，让侧耳、遮脸和拖行在直播缩小画面中也能分辨。白衣长发形象不作为所有敌人的统一外形。

菜单可保留“听声者”等机制名称的本地化版本；故事文本用“走廊里的人”“哭泣的身影”等观察式描述。普通威胁仍是同一时刻的一种主要追兵，哭泣身影激活时继续执行现有互斥规则。

### 声音

第一批重做或补充：呼叫铃、日文院内广播、拖鞋/鞋底脚步、推车轮声、荧光灯电流和通风背景。声音方向与距离应与场景一致，不依靠突然提高音量制造全部惊吓。

优先 4–6 句短日语广播，先审文本再录音。其他地区保留日语配音，字幕本地化；普通脚步不需要字幕，携带规则或剧情信息的广播必须有字幕。关键危险声提供可选文字提示，保证低音量或听觉辅助场景可玩。

## 6. 无限夜班与地图扩展

六关完成后解锁独立模式，日文暂用 `終わらない夜勤`，中文“无尽夜班”，英文“Endless Shift”。HUD 显示轮次与地点，例如 `第 12 轮 · 药品仓库`，不再把无限轮数称作新增固定关卡。

运行顺序：选择地图 → 生成合法物资 → 选择兼容威胁 → 安排少量环境异常 → 搜寻撤离 → 继续或结束本次值班。

- 三图采用有历史记录的抽取，避免相邻重复，也避免永远按同一顺序轮换。
- 最近两轮不重复同一具体环境事件；事件不足时允许留白，不强行凑满。
- 以四轮为一组试验“常规、取舍、高压、恢复”的节奏；数值有上限，高压轮不引入未知规则。
- 资源连续性作为第二阶段机制：保留生命和道具，给予有限恢复与基础照明保障。具体额度需要验证，不与第一阶段日恐改造同时上线。
- 每轮撤离都能结束并保存成绩；死亡结束本次连续挑战，固定篇章进度与已解锁内容保留。
- 不恢复通关三选一永久强化作为本次默认方案；先验证路线、资源和遭遇能否支持继续游玩。

第一张新增地图建议为太平间，归入同一医院篇章，新增两份固定记录，并加入无限池。它必须提供外围绕行与中央暴露区等新的路线选择。之后才评估急诊大厅。

学校、旅馆、住宅等作为后续独立篇章，分别设计职业/来访动机、道具与异常来源。首版无限夜班限制在医院内部，不把各种日本场景无解释地随机拼在一起。

## 7. 全球本地化规则

### 内容分层

| 内容 | 日本版本 | 其他地区版本 |
| --- | --- | --- |
| 游戏 Logo | NIGHT SHIFT | NIGHT SHIFT |
| 世界设定、建筑、人物 | 日本地方医院旧楼 | 保持一致 |
| 墙面标识与道具标签 | 日文原物 | 保留日文；关键交互附本地化名称 |
| 菜单、HUD、任务、错误信息 | 日文 | 完整本地化 |
| 广播、角色语音 | 日语 | 同一音轨 + 本地化字幕 |
| 关键纸条与巡查记录 | 可读日文正文 | 打开时显示本地化正文，可查看原件 |
| 宣传文案、商店介绍 | 日文原生撰写 | 按目标语言改写，准确表达同一玩法 |

门上的 `薬品庫` 可以保留；靠近时英文玩家看到 `[E] Open medicine storeroom`，中文玩家看到 `[E] 打开药品库门`。关键信息不能要求玩家读懂日文或从低分辨率图片辨字。

### 文风

日文制度性文本用简短可信的通知语气，任务用直接动作句，异常用具体观察。中文与英文保留这种语气，不逐字搬运日文语序，不加原文没有的恐怖形容词。

| 用途 | 日文工作稿 | 中文 | 英文 |
| --- | --- | --- | --- |
| 异常观察 | 誰もいない病室から、ナースコールが鳴っている。 | 空病房里，呼叫铃还在响。 | The call bell is ringing in an empty room. |
| 缺少钥匙 | 薬品庫の鍵が必要だ。 | 需要药品库钥匙。 | You need the medicine storeroom key. |
| 撤离提示 | 非常口の電源が復旧するまで、あと8秒。 | 出口供电将在 8 秒后恢复。 | Exit power returns in 8 seconds. |

计时类示例实际使用插值，不硬编码数字。功能提示先保证明确，剧情文字可以保留悬念。

### 实现要求

当前 `src/i18n.ts` 只支持 `zh-CN` 与 `en`，默认中文；两个 locale 文件已覆盖部分菜单，但 `src/endless.ts`、`src/run-rules.ts` 等仍有直接中文。新增一个日文 JSON 不能完成日语版。

后续实施需要：

1. 增加 `ja`，人工选择优先于浏览器语言；首次访问按浏览器语言选择已支持语言，其他语言回退英语，不能在切语言后改存档进度。
2. 全量抽离菜单、HUD、教程、交互、结算、环境事件、怪物提示、观众效果与音频状态；事件配置保存消息 key 与参数。
3. 地点 ID、关卡 ID、怪物 ID 与显示文字分离；不得以中文或日文名称参与规则判断。
4. 使用具有日文假名、常用汉字与所需标点覆盖的字体。现有中文像素字体能否满足日语需要单独检查，不默认沿用即可。
5. 原生日文场景标牌作为美术素材；可读正文由文本层承担，避免为每种语言重画全部背景。
6. 检查日文禁则、英文长度、换行、插值、字幕停留时间、字体缺字和小窗口；字体及配音的具体资源在实施时确定。

## 8. 直播互动

沿用现有四增益/四减益及内部 command ID，外部协议不随日文命名变化。展示名称和反馈本地化。侦察、补给、击退、庇护说明实际效果；干扰优先融入断电、广播和位置暴露等医院表现。

礼物反馈放在现有独立反馈区，不覆盖关键物体和字幕；暂停与结算期沿用不作用于游戏的规则。付费干扰和自动遭遇共用危险预算，不打断首次教学或最终供电高潮，不直接在玩家脚下生成致命威胁。

环境异常中至少一部分应能在直播画面里看清，但不要求主播看聊天才可通关。暂不增加投票、多结局付费或强制日语语音识别。

## 9. 制作阶段与验收

| 阶段 | 交付物 | 验收重点 |
| --- | --- | --- |
| A：方向样片 | 第一关日恐版、值班台、代表场景、3 个环境事件、完整日语单关流程 | 场所和工作身份可信；日本玩家能看懂并完成；直播画面可读 |
| B：首组三关 | 三图基础改造、各 4 个环境事件、前三份记录、日英中完整文本 | 每图身份不同；规则与预告一致；无关键文字漏翻 |
| C：完整六关 | 后三关路线/事件差异、结局、稳定关卡 ID 与存档迁移 | 后半不是重复填充；结局成立；老存档不会因地图增加错位 |
| D：无限夜班 | 独立轮次、受约束抽取、资源连续性、成绩记录 | 反复进入同图仍改变选择；有恢复时段；新增地图不重排固定关卡 |

前三关做出可验证体验后再扩大美术投入。工期需在代表场景和第一关样片完成后，按实际素材制作与日语审校成本估算，本案不承诺周数。

试玩首轮建议邀请 5–8 名日语母语玩家，其中 2–3 名具有游戏直播经验；另找少量非日语玩家检查保留日文环境后的理解情况。该规模用于发现问题，不用于推断市场规模或付费表现。

重点记录：第一次卡住的原因、关键提示是否理解、危险预告是否识别、后半关是否被认为重复、主动继续情况、声音/物体是否适合直播观看。将“看不清”“不知道规则”“知道但操作失败”分别记录。

技术验收沿用地图完整钥匙链与可达性、哭泣身影安全路径、暂停/换关事件清理及实际键盘通关检查。新增日文全流程检查与三语言布局检查。文档审阅、文案审校不替代实际游玩验证。
