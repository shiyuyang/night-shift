# 无限轮次如何减少重复

当前 0.4 已完成基础循环：三种几何布局、每图两组物资位置、通用钥匙、开箱取保险丝、可连续结算、闪光/诱饵/治疗、八种观众指令。它是可玩的循环骨架，不是长期耐玩性已经完成。

本次已接入前三项，后续按剩余优先级推进：

1. **已实现：怪物行为差异**：声敏型（诱饵有效、慢走可避）、畏光型（闪光有效）、巡逻型（观察路线、关门阻挡）。每轮先清楚提示本轮威胁及可用反制；不能把不告诉玩家的免疫作为难度。
2. **已实现：每轮一个事件**：供电维护、补给充足、静默巡查，改变路线或资源选择，不同时堆多项。与地图和怪物组合，但验证不会使钥匙或出口不可达。
3. **已实现：阶段选择**：每三轮在更长闪光定身、更长诱饵、额外绷带中三选一，限制叠加上限。让玩家形成策略，同时控制后期数值失衡。
4. **有价值的分岔**：通关物资路线之外设置可选补给箱，选择多搜一次还是立即走。关键钥匙保证可达，任何随机生成都要校验依赖关系。
5. **观众改变决策**：侦察能减少搜索、声源能打开逃跑窗口、补给能支撑反击。干扰事件有提示、时长和冷却，不能用连续付费事件锁死玩家。
6. **节奏**：搜寻、异常、追逐、恢复交替。控制同时存在的高压事件数量，留出主播讲话和观众发现异常的时间。

验收重点是玩家是否在相同地图上作出了不同选择，而非仅统计多少地图/贴图。记录退出轮次、卡住位置、钥匙寻找耗时、道具使用率和主动继续率；数值需要真人试玩验证。
