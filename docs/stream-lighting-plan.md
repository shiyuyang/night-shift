# 直播可读性与手电价值（待实施方案）

目前普通场景遮暗 94%，断电 97%；直播压缩后容易把地板、家具、怪物的暗部压成同一片。需要提高暗部层次，而不是新增大量灯具。

- 世界底色：先将普通遮暗试调到 90%、断电 94%，保留低饱和冷灰的墙、地板、家具轮廓。此值仅为首轮对比起点，不代表最终验收。
- 暗处细节：采用少量稳定的暗部色阶，减弱暗区细密雪花，避免压缩噪声淹没人影。避免用高频颗粒增加恐怖感。
- 人物：稳定保留玩家全身轮廓、走路方向和近处威胁的动作，不增加随身照明范围，不做发光描边。
- 手电：维持方向、遮挡和有效距离；照射区域有更丰富的颜色与物体细节，提供远处信息与畏光者压制。暗处可看出有柜子，照亮或走近才容易分辨柜子类型。近距离交互不强制耗电。
- 环境灯：维持现有灯数及覆盖范围，只负责少量暖冷色对比、出口识别和空间焦点。提高视觉底色不算真实光源，也不压制畏光者。
- 断电：固定主灯熄灭、彩色区域消失，伴随已有声光预兆，依旧能看懂玩家朝哪里逃跑。

验证：同一场景固定镜头截取开灯、关灯、断电三张图；在 720p 缩放及模拟直播压缩后比较人物、出口、墙边与危险动作的可辨认程度。再验证手电仍能明显增加远处细节，并且熄灯、没电仍可以通关。当前实现仅修复寻路，未套用这些画面数值。
