# 无限模式：行为与阶段成长

本次在原有搜寻循环上加入三个相互配合的系统。

- 听声者记录疾跑和交互声的位置，记忆衰减后停止追踪；诱饵可转移注意力。畏光者被正面手电照射时移速降至四分之一，闪光额外定身两秒。巡逻者沿可通行网格追踪，移动仍经过实体碰撞检测，关闭的门可阻挡它。
- 每轮显示一种事件：追逐间隔更长、闪光器额外补充一个、每三十秒环境灯断电四秒。事件和威胁随轮次轮换，同一地图再次出现时组合会变化；不会随机封死物资路线。
- 每三轮通关后必须选一项阶段补给，才能继续。闪光时长、诱饵时长、每轮绷带数量分别最多强化三级。继续挑战保留强化，重试或新开挑战重置。全部满级后不再要求选择。

门可从两侧开关，门口有玩家或巡逻者时不允许关门嵌入角色。门与未开启箱子的交互范围重叠时，优先选择更近的目标。观众的驱散和诱饵指令享受对应强化。

本次没有增加怪物专属美术：三种行为共用既有角色图集，以色调区别。地图仍为三个模板、六组物资配置，轮换规则也为确定性规则。行为差异与成长系统增加决策空间，实际长期留存和难度曲线仍需试玩反馈。

验证包括强化资格/重复领取/等级上限、灯光方向与有效距离、巡逻者开门可达/关门隔离，以及真实键盘连续搜寻、房内开关门、三轮结算选择与跨轮强化延续。

## 逐关入口与氛围回补

主界面现在选择关卡，初始仅开放第一关；胜利解锁下一关，已通过的关卡可重玩，解锁进度保存在当前浏览器。没有改变保险丝逃生条件，阶段强化仍属于连续挑战。

对照旧剧情场景发现，新循环未接入家具投影、局部坏灯与薄雾。现已回补家具朝光源反向投影、环境灯局部间歇故障、墙面成组渗污、远离角色的低透明度雾，以及无追逐时的错拍脚步和铁架声。角色近身照明保留；环境声不扣血，不改变怪物或物资判定。选关改为暗色档案卡片。

## 光影实现修正

光影拆到 `src/light-renderer.ts`。墙体使用射线与矩形的精确交点及墙角采样，替换固定步长探测。手电使用预生成的角度/距离衰减纹理，避免硬扇形边缘。每盏灯单独在离屏画布计算家具遮挡，再合成场景亮度，其他灯可以补亮阴影；另加短接触阴影。保留角色局部可读性。此实现仍是 Phaser 场景上的二维遮罩，并非物理光照。

`npm run test:browser:lighting` 检查实际 Canvas 像素：墙后遮暗、家具投影、第二光源补光、手电角度渐变和射线平行边界；同时截取正常/断电画面并检查运行时错误。


## 专用钥匙与日常异样

用三种对应锁的消耗钥匙替代通用钥匙。红牌钥匙来自无锁箱，仅首次解锁病房门消耗；铜钥匙开启铜锁箱，得到蓝牌钥匙；蓝牌钥匙开启房内最后一个箱子。每箱有保险丝，钥匙不会误用于其他锁，防止资源误用造成死局。

暗光小物体采用代码绘制的像素簇，沿用场景像素密度：电话琥珀灯、旧 CRT 绿光、供灯暖光。配合纸符、小人偶转向和地面使用痕迹。未增加复杂解谜或怪物伤害数值。日系氛围方向参考开发者对《夜勤事件》的夜班情境、VHS 美学及心理恐怖描述：https://chillas-art.itch.io/the-convenience-store 。本作中的人偶、供灯和钥匙规则是独立设计。
