# 0.3：像素语言、步态、实体与配乐

> 历史设计记录：旧双夜剧情及其测试已删除，本文不代表当前运行机制或可执行测试。当前规则见 README 和 difficulty-progression.md。

## 已实现

- 不再缩小拟真人物和斜视病床：改用 v4 色块角色、正俯视病床，以及同轴的程序化柜子、轮椅和配电箱。地面去掉高频纹理噪声，UI 去掉照片式金属材质，封面显示实际游戏画面。
- 人物上半身固定使用各方向的站姿，腿部按实际移动距离循环，减少生成帧之间装备翻转。每 10 像素切换一个腿部阶段。松键、撞墙或顶住家具时回到站姿；转向不再依据全局时间跳帧。
- 家具完整占地与墙体一起参与碰撞。人物碰撞范围位于世界锚点下方 8–16px，宽 14px。移动按最大 3px 的子步推进，先横后纵，防止帧间穿透并允许沿边滑行。
- 床的遮挡深度以实体下沿为基准，人物以脚底为基准。物体不再只是装饰；接待台、柜子、轮椅和配电箱都阻挡通行。谜题和道具互动位置仍在可到达的地面上。
- 灯光保留墙体遮挡，床影沿灯源反方向投射并排除物体本体。视野镜头为 1.3 倍近景，地图无法同时全部看见。
- 加入短暂病房人影、第一次拿到保险丝时的短暂断电；不使用怪物透明光晕或频繁闪烁。
- ElevenLabs 生成 40 秒探索和 24 秒追逐配乐。仅用户开启声音后解码；危险程度驱动两层混合，循环首尾有 1.4 秒交叠，暂停/结束/关闭声音时主音量淡出。

## 验证

`npm test` 包含四向床碰撞、大步长防穿透、侧向滑行、步态距离/站姿、谜题状态与事件处理。`npm run test:browser` 包含真实浏览器中的病床南北阻挡、绕行、停止动画、第一夜通关、素材透明度、音乐解码以及原 webhook 与布局回归。`npm run test:browser:night2` 沿碰撞可行路线，实际按键完成第二夜。

开发环境提供只读 `window.__nightshift()` 状态快照，让测试观测脚底、实体、实际位移和帧号。它不能修改位置或背包，生产构建不会安装该接口。浏览器导航测试使用快照规划路线，通过真实按键行走，不绕过物理移动。

## 限制

怪物仍遵循原先的幽灵设定，可以穿过实体；人物绝不能穿过。怪物状态机、空间录音和更精确的手工方向动画仍有打磨空间。合成短音效仍用于脚步和金属提示，背景音乐已替换为生成录音。移动端仍是观看/互动布局，角色操作需要键盘。

最新素材路径与完整生成/透明背景编辑提示词见 [art-v4-prompts.md](art-v4-prompts.md)。

## 2026-09-05：标题音频、攻击反馈与结算

- 点击“进入值班台”即在标题界面播放已有本地配乐；直接开始也默认启用。浏览器首次播放仍需要用户手势。主动静音后重开游戏保留静音。结算回到探索配乐，暂停淡出。
- UI 使用统一深灰绿监控机壳、纸色文字和矩形控件，默认收起观众控制台，设置入口会自动展开。标题背景保留真实关卡渲染。
- 怪物距离 260 像素内逐渐增加全画面暗角与监控干扰；命中叠加 850ms 抓痕/红黑边缘、240ms 镜头震动、低频撞击音。保护状态降低逼近反馈。叠层不拦截输入、不改变碰撞。
- 结算展示关卡、用时、生命、保险丝、第二夜任务完成情况以及结束原因。第一夜胜利提供进入第二夜入口。
- Progression 统一控制保险丝访问、送电和逃生。第二夜要求病历、药柜、撬棍、封板、3 个保险丝及供电；不能仅凭保险丝计数胜利。第一夜保持收集入门流程。
- 单元回归覆盖第二夜三保险丝但未解谜/未供电的拒绝路径；浏览器回归覆盖默认音乐、标题音乐、怪物逼近/命中、实际通关与结算、提前逃生拦截。

## 药柜解谜的安全交互

药柜打开期间冻结游戏时间、怪物移动、伤害、电池消耗和事件倒计时；保持背景配乐。关闭按钮、Escape 和正确解锁均经同一退出逻辑恢复游戏，并给予至少 3 秒免伤保护，不缩短已有的观众庇护。错误答案不立即召唤怪物，改为退出解谜后触发一次警报。解谜期间收到的观众命令延后到关闭时执行，同类命令合并一次，避免积压突发攻击。重新开始会清空延迟事件。

第二夜浏览器回归先召唤真实怪物，再打开药柜并输入错误答案，验证读取期间时间、生命、电量和怪物位置/倒计时均不变；验证 Escape 和正确解锁后的保护时间，最后完成第二夜逃生。

## 空间氛围：重复、遮蔽与环境异常

参考方向（不复制角色/贴图）：[ArchDaily 对后室与阈限空间的分析](https://www.archdaily.com/996668/why-are-liminal-spaces-eerie-the-case-of-the-backrooms)；[Bloober/KONAMI《寂静岭 2》声音开发访谈](https://www.youtube.com/watch?v=KdXbYYioUUY)。本轮将重复的封闭观察窗、灰黄旧墙面与冷色地面并置，用断续照明而非全图均匀暗色建立空间层次。

镜头从 1.3 缩近至 1.65；手电照射距离与角度缩短，玩家脚边保持填光。雾由低分辨率缓慢漂移的分层场绘制，墙体区域不画雾，人物近处较淡。添加潮湿积水、轮印、剥落墙面、病床隔帘；实体隔帘接入家具碰撞。第一次取得保险丝后中段灯管变暗，并出现不造成伤害的脚印。

原先固定在远处、只显示 1.4 秒的人影改为第 7 秒之后寻找玩家附近、连线无遮挡的位置，停留 3 秒并消退。没有合法位置时延后；该人影不造成伤害。解谜与暂停仍冻结这些事件。

## 材质与色彩压暗

地板、墙漆、柜体和隔帘的基础颜色改为低明度灰蓝/灰褐；病床与角色贴图增加冷灰色调制，画布饱和度降至 48%。环境暗层不透明度从 91% 提至 96%，常亮灯强度从 85% 降至 48%，脚边填光缩小至 64 像素，手电缩至 205 像素。雾颜色和密度同步降低，避免雾将黑处抬成浅灰。外围监控台改为深炭灰，功能文字保留对比度。

## 第一夜：红灯、预兆与一次性惊吓

西北病房入口新增局部红色应急灯，靠近 125 像素范围内触发一次门后声音与两次相隔一秒以上的短促灯光衰减。地面有床边至门口的断续拖痕和擦拭手印。第一枚保险丝取走后，断电 1.3 秒，在第 1.15 秒出现持续 0.48 秒的人影叠层与现有受压缩器控制的撞击音；不造成伤害、不阻止移动，每局一次。减少动态效果偏好下禁用这次镜头震动。事件由游戏时间驱动，暂停/谜题冻结，重开重置，结算清理。

浏览器回归验证惊吓实际出现和消失、计数为一次、生命未损失以及之后仍可正常通关。

## 独立结束流程与窗口视觉

通关/死亡不再复用标题开始层。结束后现场停止，约 0.75 秒后独立巡逻档案渐入；标题保持隐藏。结算提供重新值班、主动返回标题，第一夜通关提供进入第二夜。重新值班直接开局；仅返回标题按钮恢复关卡选择。结束 HUD 渐隐，减少和报告文字叠加。动画遵循减少动态效果偏好。

药柜、病历、结算统一为深色档案面板：外框/内边、档案抬头、分隔线、数据栏、主次按钮。密码输入使用分槽机械刻度视觉，按钮补齐 hover、focus、pressed 状态。浏览器回归覆盖真正被怪物击杀后显示失联档案且不显示标题，以及主动返回标题；第二夜完整通关后检查独立结算。

## 第一夜观察事件：监控、呼叫与第七张床

护士站（西南接待台，靠近按 E）提供 01 床监控和六床交班记录。尚未取保险丝时画面为空床；取得第一枚保险丝后监控中出现人影，现场床铺只有凹痕。监控采用游戏当前床/怪物图集绘制固定观察画面，作为叙事影像而非实时摄像头。

第一枚保险丝引起隔离区 06 床呼叫。在护士站取消后，离开查看界面两秒，呼叫转移到西北 01 床；靠近该床脚按 E 可取消。双音呼叫带左右声像，床脚按钮有同步灯光。

异常监控出现后，西北病房多出一张床，碰撞同时加入；检查床脚卡片显示“夜班值班员 / 工号 07”。检查后离开病房，床消失并留下轮印；再次看监控不重生床。重开清空所有状态。场景不主动宣布床数变化。

这些观察事件不强制阻挡原有第一夜逃生。监控查看冻结模拟时间与伤害，退出后有 3 秒保护，观众事件延后处理。当时的旧剧情测试覆盖事件转换，并验证两次监控影像差异、呼叫转移/取消、额外床碰撞/床头卡、消失痕迹、通关和重开复位。
