# 苍白之影：近身压力与落点可见性

基线为 `37e3730`。本次根据试玩反馈缩短出现距离、增加追随速度，并处理隔墙刷入另一房间和上半身过暗的问题。距离和速度均使用游戏世界坐标，不是浏览器屏幕像素。

| 参数 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 首次出现目标距离 | 100 | 72 |
| 再次闪现目标距离 | 90 | 68 |
| 拉远后闪现阈值 | 210 | 150 |
| 移动速度 | 36 / 秒 | 48 / 秒 |
| 最短闪现间隔 | 3 秒 | 2.5 秒 |
| 显形安全期 | 0.65 秒 | 0.65 秒 |

落点在玩家当前连通区域中搜索，保留至少 55 的安全距离。苍白之影优先选择短步行范围内、视线和脚部移动都无遮挡的位置，再按目标距离排序，距离相近时优先背后。附近没有直接接近路线时，退到步行距离最短的合法候选，不再仅凭隔墙直线距离选点。此规则不依赖不完整的房间标签；敞开门口仍可能被视为同一片可见空间。

迷失通道继续使用原有的距离排序，未套用苍白之影的落点规则。单实体、每份 20 秒累加、暂停冻结、道具无法驱散及接触击杀保持原有行为。

白衣染色从 `#a8b6b4` 调到 `#cbdad8`，正常透明度从 0.85 到 0.95。局部冷光中心从脚部上移到躯干，半径 60 → 88，强度 0.32 → 0.60，随显形闪烁减弱，并继续受墙体和家具遮挡。

后续视觉调整将迈步图集换成四向并腿漂浮图集：双腿并拢、脚尖下垂，身体上移 8 个游戏像素，保留幅度 2 像素的轻微浮动。物理位置与接触判定不随视觉高度改变。生成源图、提示词与处理记录保存在 `public/assets/gift-shade-float-v2-*`；`scripts/pack-gift-shade.cjs` 负责透明背景转换及 64×80 帧打包。送礼提示整体放大 12%，继续使用统一 HUD 坐标和窄屏缩放。整体环境对比度仅完成研究，尚未调整。

## 验证

- 隔墙双房间案例：两房在墙下方连通，旧算法选择相邻房间；新算法在四个朝向、五个随机取值下都选择玩家这一侧的无遮挡落点。
- 七夜、每夜三个地图种子，在出生点与合法区域中心进行 756 次落点检查，全部合法、满足安全间距且视线无遮挡。
- 同批地图位置的 567 次迷失通道落点与基线完全一致。
- Chromium 实际游戏检查：附近出现、局部信号撕裂、无手电及断电时的上半身辨识、微光随显形闪烁、暂停冻结、连击续时、接触击杀与清理通过。完整礼物回归也通过，包含 29 种语言。

受控空场模拟使用六个固定随机种子、0.05 秒步长，移动样本持续 20 秒。下表为六次平均值；近身范围定义为距离不超过 120，包括显形安全期。

| 场景 | 调整前 | 调整后 |
| --- | ---: | ---: |
| 原地不动到接触 | 3.37 秒 | 2.05 秒 |
| 持续步行时处于近身范围的累计时间 | 3.49 秒 | 8.07 秒 |
| 持续疾跑时处于近身范围的累计时间 | 2.35 秒 | 4.42 秒 |
| 持续移动时再次闪现次数 | 6 次 | 7 次 |

步行速度为 83，疾跑为 125。十二个持续移动样本都能逃开，没有被强制击杀。结果说明停留空间缩短、跑远后的压力更快回来；空场模拟不代表完整关卡难度，也未模拟疾跑体力、开箱停留和普通怪物夹击。原始数据和前后截图在 `output/shade-pressure-20260911/`。
