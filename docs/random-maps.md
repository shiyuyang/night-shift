# 有约束的随机搜寻

当前版本按试玩反馈收敛：**房间不随机拆分，物资局部变化。**

- 首关保持固定 LDtk 教学。
- 第二关起保留原 LDtk 隔墙、家具阵列、主走廊、门、灯位和事件区域。
- 钥匙及前两箱从每主题 12～15 个预设点中不重复抽取，最后封箱从锁闭房间的 5～7 个点抽取，且不可与家具、墙、门或其他物资重叠。
- 种子可复现，最多 12 次尝试；失败使用经过校验的原地图物资点。
- 三主题 24 个 LDtk 家具模块仍保留于 maps/rooms，但当前不再随机拼入地图。
- 最多放置一个补给药柜、一个藏身柜，避开主走廊与主线交互；柜前必须可达，两个柜子的扩大安全区作为障碍也必须可通关。

`src/runtime/level-validation.ts` 使用真实玩家碰撞尺寸，对开门前后分别搜索：铜钥匙、无锁箱、铜锁箱和门可交互；封箱不可隔锁门获得；开门后三箱与出口可达；怪物出生区域连通。这保障几何与钥匙流程，不保证玩家不会被追击击败。

`tests/random-level.test.mjs` 检查 600 个主题/种子组合、固定建筑和家具、物资变化、确定性、回退及不可达反例。实际浏览器测试沿键盘操作完成搜寻和逃生。

## 逃生路线约束
三张 LDtk 地图的 EXIT 与出口应急灯移至西侧，最后的封箱仍在东侧锁闭房间；出口标识由实体位置绘制。玩家必须拿无锁箱与铜锁箱的钥匙才能进入并开启最后封箱，不能通过留一个出口旁的箱子最后拿来缩短路线。
验证器对真实可通行位置做多源最短路，计入开箱半径 44、出口交互半径 37，要求最后封箱到出口的最短可行距离至少 600 世界单位。生成图与保底图均受此限制。当前六个原始摆放版本分别为 776 / 1072 / 800（两轮相同），以步行 83 计约 9.3 / 12.9 / 9.6 秒，不含躲避怪物或关门时间。

搜寻点表：game/search-spots.json。所有组合继续经过完整钥匙链、碰撞和最短撤离距离校验，非法组合重抽。
