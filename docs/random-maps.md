# 有约束的随机搜寻

七张地图均为 1280×768。建筑、家具阵列、门、灯与功能分区固定，仅在房间内的候选位置之间随机。首关病房保持固定教学；后续轮次使用可复现种子。

## 分用途候选点

`game/search-spots.json` 按主题定义 key / free / brass / sealed 四组非空位置池：

| 地图 | 铜钥匙 | 无锁箱 | 铜锁箱 | 最后封箱 |
| --- | --- | --- | --- | --- |
| 病房 | 护士站 | 普通病房 | 治疗室或布草间 | 隔离室 |
| 仓库 | 收货区 | 货架间取货通道 | 发药间 | 锁闭药库 |
| 机房 | 值班室 | 工具间 | 东侧或南侧检修区 | 配电室 |

随机后检查物资身体不重叠、不与家具和门相交，按完整钥匙链验证开门前后的可达性。最多尝试 12 次，失败回到经过同样校验的 LDtk 固定摆放。不会通过放宽可达性要求接受非法种子。

## 可选家具

每图最多一个补给药柜、一个藏身柜，候选区域来自 LDtk 的 Optional*Zone。区域位于工作间或房间侧面，不在主通道、货架端头或锁门口随机塞柜子。

验证器将柜子的扩大安全区视为障碍，重新验证钥匙链，并检查每个柜子正面均可接近。安全区域不足时允许不生成。旧版 maps/rooms 的家具模块保留，但不参与当前随机拼图。

## 撤离约束

EXIT 位于西侧，最后封箱在东侧锁区；必须取得无锁箱和铜锁箱中的钥匙才能进入并开启封箱。最短撤离距离考虑实际可通行位置、开箱半径 44 和出口交互半径 37，要求至少 600 世界单位。

当前 LDtk 固定 A/B 布局分别为：病房 1088 / 1136，仓库 1216 / 1160，机房 1152 / 1168。它们是几何最短路，不包含搜寻、回避追逐和直播互动。

## 验证

`tests/random-level.test.mjs` 覆盖 1,400 个主题/种子组合、种子确定性、固定建筑、分用途区域、完整钥匙链、不可达反例和保底流程。本轮得到 922 种物资组合、0 次保底回退；具体数据属于本轮快照，不是跨版本承诺。

`tests/levels.test.mjs` 使用实际玩家与追兵身体尺寸检查病房工作间回环、仓库横道及机房检修环。浏览器入口为 `npm run test:browser:ward-expanded` 和 `npm run test:browser:industrial`，使用真实键盘及交互，有庇护辅助；不作为无援助难度结论。

新增门诊物资分布：挂号区 / 诊室 / 检查区 / 治疗室。手术室物资分布：准备间 / 清洗间 / 手术区 / 无菌库。详见 `clinical-maps-validation.md`。

太平间物资分布：值班室 / 清洁间 / 辨认区 / 冷藏锁区。两种抽屉状态均参与可达性检查；详见 `morgue-validation.md`。

医院中庭物资分布：门卫室 / 温室 / 养护区 / 工具房。详见 `garden-validation.md`。
