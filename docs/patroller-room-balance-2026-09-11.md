# 第三夜巡逻者与关门等待复查

基于冷光分支 `64d89e4`，针对“日常贴身难甩脱、最后一箱后关门却没有压力”分别复现。两者原因不同，不能一起加速或一起削弱。

## 结论与改动

1. **主怪的警报目标分配错误。** 最后一箱会给原来的巡逻者分配出口路线上的交会点；第三夜哭泣者介绍期结束后重新出现的主怪，还会把最后已知位置也写成这个交会点。玩家留在房里时，主怪没有房内线索，走完路线就恢复普通巡逻。
2. **转角脱离的门槛高于实际遮挡时间。** 第三夜货架边的两组冲刺绕行，最长连续遮挡只有 0.50 / 0.70 秒，达不到原来的 0.75 秒，减速搜索没有触发。

主怪现在沿合法路径调查最后一箱的警报位置；门挡路时会撞门。哭泣者介绍保护在请求主怪前结束。警报位置是一次记录，之后仍由真实视线、声音、道具及到达后的搜索更新，未增加持续定位。第四夜开始的增援继续负责出口。

主怪巡逻者和出口巡逻者的视线中断门槛改为 **0.35 秒**，其他怪仍用 0.75 秒。重获视线仍需要 **0.9 秒**，极近接触仍可立即锁定。数量、速度、伤害、体力、道具和破门秒数均未调整；第三夜仍需连续撞门 **3 秒**。

## 关门等待：真实第三夜流程

使用正常生命、体力、物品数量，从开场按普通策略实际获取钥匙和三个保险丝；随后步行至门内侧，按 E 关门并原地等待，不再用道具。不传送玩家，不给无敌，不关闭哭泣者。种子 2 同时执行真实渲染，保存撞门画面。

| 种子 | 修改前 | 最终修改后 |
| --- | --- | --- |
| 0 | 主怪已经进屋，关门后仍被攻击 | 同样保持近身威胁 |
| 1 | 门保持关闭，等满 30 秒没有受伤 | 警报后 12.20 秒破门，通电前进屋攻击 |
| 2 | 门保持关闭，等满 30 秒没有受伤 | 警报后 12.05 秒破门，通电前进屋攻击 |
| 3 | 门保持关闭，等满 30 秒没有受伤 | 警报后 12.05 秒破门，通电前进屋攻击 |

这些等待样本是故意不反抗的压力回归，死亡不代表普通玩法应当有这样的失败率。自动策略直接回出口的整局通过率，不能替代这项检查。

回归：`tests/finale-room.browser.mjs`；最终轨迹与渲染图：`output/balance/finale-room/`。

## 货架绕行：不使用道具的对照

使用第三夜、种子 3 的真实货架和碰撞。明确隔离其他怪物，保留巡逻者、正常生命和体力。初始距离为 40 / 80 世界单位，沿同一条事先确定的绕行路线前进，比较全程步行和开头冲刺 2.8 秒。路线最后绕回追击区域，用于检查重新遇怪。

| 初始间距 / 操作 | 原先减速搜索时长 | 修改后减速搜索时长 | 冲刺结束后最大间距：前 → 后 |
| --- | --- | --- | --- |
| 40 / 步行 | 0 秒 | 0 秒 | 86 → 86 |
| 40 / 冲刺绕角 | 0 秒 | 4.3 秒 | 95 → 230 |
| 80 / 步行 | 0 秒 | 0 秒 | 86 → 86 |
| 80 / 冲刺绕角 | 0 秒 | 4.9 秒 | 127 → 225 |

冲刺组在绕回视线后仍重新被追上，各损失 20 生命；步行组各损失 40 生命。改善的是实际拉开距离的机会，不是自动脱战或永久安全。这里的“减速搜索”是视线状态，不等于基准测试中所有敌人同时失去线索的完整脱战指标。

回归：`tests/patroller-corners.browser.mjs`；最终轨迹：`output/balance/patroller-corners/report.json`；前后原始对照：`output/balance/patroller-door-diagnosis/corners-before.json` 和 `corners.json`。
