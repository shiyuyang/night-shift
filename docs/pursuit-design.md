# 大地图追击与游荡哭泣者

每张 LDtk 地图新增 8 个 `MonsterEntry`，作为可选接近入口。固定的 `MonsterLeft` / `MonsterRight` 仍用于退场与地图连通性校验；可选入口不占用物资和储物柜位置。运行时排除被家具覆盖、不可达、距离玩家不足 180 单位或当前可见的入口，按实际寻路距离选择接近时间最接近 5.5 秒的入口，并保留 3 秒声音预警。

巡逻怪物丢失目标后先走向最后感知位置，再搜索附近可达方向 12 秒。目的地被门或柜子挡住时，使用最近可达位置；搜索不读取躲藏玩家的新位置。25 秒未再次感知且相距超过 300 单位时允许退场。38 秒未发生近距离威胁后，下次追击等待最多 6 秒；原有恢复期与哭泣者攻击互斥仍然生效。

哭泣者使用手电实际范围（正常 250、低电量 190）的 96% 判定受光，墙体和遮挡仍生效。110 单位外持续照射的初始积怒速度减半，保留抬头、站起和攻击预警。每关至多一名哭泣者，在可达入口之间以每秒 32 单位游荡，首次等待 7 秒，到点停留 6–10 秒。游走时停哭，到点恢复哭声；察觉玩家时停步。闪光、追逐、碰撞和返回均保留物理移动。

Chrome 是运行目标。音乐和音效包只交付 Opus，解码失败不切换 MP3；MP3 仅保留为素材源文件，不进入发布目录。两个部署脚本均移除 MP3 回退测试。历史媒体审计中的兼容回退描述不再代表当前行为。

验证入口：`npm test`、`npm run test:browser:pursuit`、`npm run test:browser:encounters`。浏览器专项使用真实地图中的可通行走廊布置可重复场景，并检查实际场景更新、动画帧、键盘闪光、预警、搜索移动和暂停。
