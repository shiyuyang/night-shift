# 病房扩图验证

分支：`codex/hospital-new-levels`；基于本地 main `a9cd97d`。本文记录第一阶段病房扩大到 1280×768 的验证快照。后续仓库与机房也已扩图，当前结果见 [仓库与机房验证](industrial-maps-validation.md)。

## 实现

- 修改 LDtk 源文件，按功能重排六间房；保留主廊与一处工作间回环。新增 Desk / Shelf 家具种类，使用程序绘制的桌面、纸张与布草层架，床仍为 38×76 世界单位。
- 物资使用分用途候选点；首关不随机。后续病房轮次使用护士站、病房、治疗/布草间、隔离室四组位置池。既有钥匙链、重抽和保底校验保留。
- 增加两处房间灯，重新布置注册灯、怪物节点与场景摆件。可选补给/藏身柜从房间区域采样，不再限制在旧病房坐标内。
- 浏览器导航工具和地图测试读取真实出生点、边界与门位置；不再假定所有地图为 960×576。

## 验证口径

本轮结果：内容检查、生产构建、90 项自动测试及病房浏览器完整撤离均通过。浏览器无运行时错误；有庇护的固定路线样例游戏计时约 44.55 秒、移动约 3411 单位，其中最后撤离约 14.12 秒、移动约 1129 单位。这一脚本已知所有目标位置并持续获得庇护，不能代表真人搜寻或正常难度。

`output/ward-expanded/layout-overview.png` 是暂停后缩小镜头并关闭光照遮暗的布局检查图，不是正常游玩视野；其余区域截图保留实际灯光和镜头。

- `npm run content:check`：LDtk schema、实体边界、灯光与事件引用。
- `npm test`：碰撞、怪物寻路、钥匙链、随机布局、遭遇和资源规则；新增玩家/怪物工作间回环检查以及按功能区域随机检查。
- `npm run build`：TypeScript 与生产构建。
- `node tests/ward-expanded.browser.mjs`：真实键盘移动，拿钥匙、依次开箱、穿南侧工作门、开关隔离门、从最东端回西侧撤离；检查镜头能覆盖旧图边界之外的区域，并保存截图与报告。

浏览器路线检查每 2 秒调用既有 sanctuary 庇护，以隔离难度因素，不传送玩家、不绕过碰撞或钥匙链。报告中的用时仅为有援助的自动路径样例，不是正常玩家平均局长、无援助难度或直播效果结论。

## 距离与随机检查

固定 A/B 摆放最短撤离距离分别 1088 / 1136，旧版为 776 / 776。第一阶段的 600 个主题/种子组合检查得到 548 种物资组合、0 次保底回退；随机检查覆盖现有三种主题。

截图和结构化浏览器报告输出到 `output/ward-expanded/`。原图与新图的真人完成时间、无援助资源压力、观众事件频率和直播反馈仍待试玩比较；地图扩大本身不是这些结果的验证。
