# 太平间：双通道与冷柜抽屉

本地分支 `codex/hospital-new-levels`，第 6 关，1280 × 768。第 7 关回到病房。尚未发布。

## 布局

北侧冷柜近道与南侧宽运尸通道平行；中央辨认区域的两个连接口位于抽屉两侧。西侧值班室放铜钥匙，西南清洁间放无锁箱，中部辨认区放铜锁箱，东侧单入口冷藏锁区放最终箱。南侧推床按停放位排列。随机点位遵循房间用途，固定建筑和家具不随机。

布局源：`maps/morgue.ldtk`。导出数据由 `npm run content:check` 生成。冷柜、白布推床为代码绘制的新家具；音乐复用现有病房曲目。

## 抽屉事件

搜寻两只箱子后，玩家靠近抽屉 300 世界单位以内，启动一次预告。柜灯及地面范围闪烁，发出铃声；至少 3 秒后检查伸出范围和 8 单位余量，玩家、可见追逐者、哭泣患者或阻路怪在场则延后。

范围空闲后先保留整段碰撞，抽屉在 1.5 秒内伸出，滑轨声使用现有金属音效。预告范围已经标出该碰撞区域，角色不会被抽屉推挤。伸出后不再收回；南侧通道保持开放。最终箱开启时，尚未执行的事件取消；已开始伸出的抽屉继续动画，但碰撞范围不再改变。暂停不推进事件，重开重新初始化。

- 太平间额外 60 个种子检查双状态可达性；两种角色体型的北侧绕行与南侧通路通过。
- 修正了太平间怪物出生点与墙体视觉安全区重叠；出生点改至运尸通道 y=500，相关碰撞回归通过。
- 按键通关种子 895950400，抽屉实际触发并绕行，完成搜寻、开门、最终箱、撤离，浏览器无脚本错误。测试使用现有 sanctuary 每 2 秒辅助，无传送或库存修改；84.2 秒为辅助测试耗时，不代表正常难度时长。
- 独立浏览器动画测试注入双箱状态与角色位置，验证占位延后、暂停冻结及完全伸出后的真实碰撞；此测试不冒充正常通关。
