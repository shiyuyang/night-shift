# 小体量恐怖游戏调研与《夜班档案》改造依据

调研日期：2026-09-05。依据开发者文章、发行商介绍和官方商店页；不是本轮逐款实机评测。下文区分来源中明确描述的机制与针对本项目的设计推演。这轮仅新增调研，不修改游戏。

## 核心判断

目前持续低明度遮住了本来就稀少的环境信息，玩家缺少观察目标。需要恢复局部可读性，建立正常状态，再让声源、物体位置或空间关系偏离正常。血痕必须可见、有方向、有上下文。游戏故障、碰撞错误与无预警扣血会破坏这种可信度。

## 当前实现需要纠正之处

1. 96% 的环境暗层与全画面低饱和一起削弱血迹、污损和房间轮廓。先调局部灯与材质对比，不继续全局压黑。
2. 脚步主要是简单合成提示音，缺少鞋底/湿脚/床轮的材质和声源差异。音乐需在异常发生时短暂降低，为细节让位。
3. 一次性近处惊吓使用放大的现有怪物精灵，缺少专门构图与动作；玩家容易理解成特效贴图。
4. 预兆字幕直接解释房间异常，使玩家较少自行观察。保留交互和玩法提示，减少替玩家宣布恐怖的文字。
5. 血污多为地面的简单图形。墙面要独立贴附污损，适应墙的立面高度、遮挡和光照；床单血迹必须画在床单上，而非落在床下。
6. 当前送礼直接触发能力，容易与剧情惊吓同时发生；需要事件调度和优先级。

## 优先制作的六种事件（以下均为原创提案）

### 1. 坏灯揭示空间变化

先让玩家看清走廊尽头的空轮椅。电流轻响，单根灯管灭约 0.35 秒，重新亮起；第二次间隔数秒才失灵。重新亮时轮椅已改变朝向。保留其他灯与脚边填光。变动发生在玩家视线离开或暗期；轮椅若实际移动，碰撞同步且不能堵死路线。

### 2. 多出来的一步

玩家连续行走后出现稍晚半拍、从身后传来的湿脚声。玩家停下，自己的步声立即停，外来声再走一到两步后停止。再次移动不必每次触发。脚步必须遵守空间距离与方向，不能每几秒随机左右播放。它可以只是预兆；少量事件在此之后有真实接近。

### 3. 墙面留下经过的证据

床边浸染 → 床沿擦痕 → 地面断续拖痕 → 门框手印，形成同一条路径。墙上高处手印提示不正常身高，门内侧抓痕暗示有人试图出来。使用干涸深褐、少量灰红边缘和极少湿润高光；不依赖全屏红滤镜。几处重点比全图均匀散点更有效。

### 4. 红灯改变信息

红色有明确来源：隔离区门上的应急灯。平时只露出门缝；靠近时亮起，照出玻璃后半个人影。红光不能铺满全图。下一次红灯亮起，人影不再在那里，玩家无法确定它是否离开房间。

### 5. 先让玩家误判，再兑现一次

门后响起撞击，门纹丝不动。玩家可以等、后退或检查。一次检查只看到松动的吊瓶。后续事件才出现真实异常，避免形成“声响必接大脸”的固定公式。假警报不能占满全部事件，否则声音会失去可信度。

### 6. 有物理来源的短促惊吓

从帘子侧边伸出的手、身后床栏猛响、玻璃后突然贴近的头部，比无来源的巨型走路精灵更符合医院空间。必须做专门动作和轮廓，短促出现后留出恢复时间。叙事惊吓与真实伤害分开；实际攻击有可察觉预兆和避让机会。

## 一个 90 秒样板段落

时间只是制作参考，触发以玩家位置、视线和交互为主。

| 阶段 | 可感知信息 | 玩家行为 | 事件目的 |
| --- | --- | --- | --- |
| 建立正常 | 护士站稳定灯、空轮椅、轻微灯管嗡声 | 观察值班表，开始巡逻 | 建立记忆与暂时安全 |
| 第一次不对 | 自己停下后，多走了两步的脚步声 | 停下、回头或继续 | 促使玩家主动验证 |
| 查找证据 | 坏灯恢复，墙上手印与拖痕可见 | 用手电查看 | 将声音关联到环境 |
| 空间改变 | 回程轮椅朝向与此前不同 | 主播与弹幕核对 | 让观众参与发现 |
| 惊吓兑现 | 隔帘侧边瞬间出现手臂并伴随床栏碰撞 | 后退或逃离 | 释放积累的紧张 |
| 恢复与悬念 | 稳定灯仍亮，额外脚步消失，帘子留下一道缺口 | 重新确认路线 | 留下痕迹而非立刻循环惊吓 |

## 直播互动

礼物提交事件请求，由调度选择合适位置和时机：坏灯、额外脚步、移动物件、短暂应急供电。连续送礼合并或排队；一次强事件之后留出恢复间隔。重要剧情正在进行、解谜暂停、死亡或结算时不叠加惊吓。援助礼物必须确实提供帮助。

观察类事件允许观众先发现；关键音频同时可用床帘轻动、灯丝颤动等视觉线索提示，但不直接标注怪物位置。不要在现场字幕提前宣布“有怪物出现”。

## 验收标准

- 普通巡逻时能辨认道路、门、关键家具和墙面污痕；黑暗中仍能导航。
- 每种声音能区分来源、位置和材质；主播讲话时关键事件仍能被听到。
- 至少一次事件促使玩家自发停步、回头或检查；这项需真人试玩，自动测试不能证明恐怖感。
- 画面变化前有正常状态可供记忆，变化后有痕迹可供核对。
- 关闭怪物攻击与屏幕覆盖特效后，样板病房仍有可读的异常。
- 像素尺寸、物体透视和碰撞一致，解谜保护、结算和静音偏好不回退。

实施顺序：先修可读性与局部光 → 制作墙面/床单污损样板 → 制作材质明确的脚步与电流声 → 建立事件调度 → 做独立惊吓动画 → 接礼物事件请求。先验证一个区域，再扩展地图。
