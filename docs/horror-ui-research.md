# 恐怖 UI 参考与调整方向（2026-09-06）

本次依据公开截图、商店展示及开发者介绍，未进行三款游戏的完整实机评测。下方的布局、数值和取舍是本项目设计建议，不是原作参数。

## 值得借鉴的做法

### SIGNALIS：界面要有明确的世界观来源
开发者明确提到，厚重 CRT 上的老式操作系统也体现在物品栏设计中；其视觉叙事使用大胆的文字排版。它的启发是让 UI 像游戏世界里存在的设备，同时赋予文字强弱和节奏。
来源：[rose-engine 在 PlayStation Blog 的介绍](https://blog.playstation.com/2022/07/07/signalis-brings-multilayered-psychological-sci-fi-survival-horror-to-ps4-october-27/)。

本项目借鉴：医院值守设备、旧标签、应急指示器作为统一视觉来源。身体状态用仪表，物品用实物图标；异常文字可以改变通常稳定的排版，但正常操作文字始终可靠、可读。

### Crow Country：把管理信息组织成专门的界面
公开物品栏截图把人物肖像、身体状况、装备和物品网格分区；健康状态使用 Fine / Caution 等文字。战斗截图中的武器和弹药反馈有明确用途。这种层次比把所有参数平铺一行更容易理解。
来源：[物品栏截图与评测](https://www.superjumpmagazine.com/crow-country-review/)、[包含开发者访谈的官方平台介绍](https://blog.playstation.com/2024/05/02/crow-country-retro-original-playstation-era-gameplay-stylings-meet-modern-horror/)。

本项目借鉴：我们只有 F/R/Q 三种即时道具，而且面向直播，仍需要常驻快捷入口；借鉴分层，不照搬完整背包管理。

### FAITH：少色、明确字形与声音共同塑造恐怖
官方定位为 8-bit 风格像素恐怖，搭配专门的动画、音乐和屏幕效果。公开截图中的文本使用强对比块状字形与大面积暗背景，清晰文字本身可以成为画面构图的一部分。
来源：[官方作品页](https://new-blood.itch.io/faith-the-unholy-trinity)、[Nintendo 官方页面与截图](https://www.nintendo.com/us/store/products/faith-the-unholy-trinity-switch/)。

本项目借鉴：恐怖文字需要少而有力；不能用低对比、小字号或持续乱码制造难读。中文要测试笔画和内白，不能直接照搬低分辨率英文字母。

## 当前问题定位
- 环境字原先固定 12 CSS px，世界文字却随游戏画面放大，视觉大小脱节。宽屏直播画面尤其明显。
- 环境事件、道具获得、一般动作结果共用相同的小字，缺乏类别与优先级。
- 生命、体力、电量、保险丝、钥匙与消耗品都挤进底部仪表条，重要程度被拉平。
- 只有背景条和描边，没有与声音、出现时机和文案配合的恐怖表达。

## 当前分区（已实施）
- 左上安全区内：与关卡信息合并的紧凑身体状态。生命保留明显刻度，减少重复文字；受伤或低血量突出显示。
- 人物附近：疾跑时显示体力，恢复满后隐去；低体力配合呼吸反馈。菜单保留完整数值。
- 下方中央：只留下 F/R/Q 三种像素道具、快捷键和次数，取消横跨状态与道具的整块面板。
- 顶部独立小区：钥匙与保险丝进度，避免与身体状态混在一起。
- 物体上方：只显示靠近时的操作、锁定条件和已搜空状态。
- 环境文字区：中下部独立字幕带；获得结果放右侧中上部，通电倒计时放上方中央。三个区域可同时显示，不共用文本或覆盖优先级。

## 环境文字的表现建议
普通环境提示用短句，桌面约 24px 起，根据实际游戏显示区域与中文阅读效果调节；关键异常可更大，但不遮挡追逐路径。厚实像素笔画、旧象牙色、局部暗色衬底。

示例：先播放真实脚步声，再出现“脚步停了。”；只有剧情中的异常消息允许短促错位与锈红强调，普通操作和领取结果保持稳定。惊吓文字到来前可以短暂压低环境声，随后恢复，避免每次提示都加高频音效或全屏闪烁。

## 本次已经落地：获得结果
独立获得结果区，两行展示“获得绷带 ×1 / 当前持有 2 个”，停留 4 秒模拟时间，暂停时冻结。对应道具格显示 +1；已满提示物品留在柜中，可消耗后再取。保险丝箱显示进度与新钥匙，独立于随后警报提示。
环境文字的基础字号与笔画已增强，HUD 分区已落地；异常消息的特殊声画编排仍是后续建议。

## 最终试玩修正
用户反馈大面板和大字号过于突兀。当前版本去掉所有常驻 HUD、获得提示、环境字幕与倒计时的面板底色/边框，只保留固定锚点、像素字、刻度、图标和薄暗色字边。字号适度随游戏显示宽度缩放，环境短句移至画面约 64% 高度，底部仅三种道具。绷带使用十字药箱图标。开局通用说明已移除。
