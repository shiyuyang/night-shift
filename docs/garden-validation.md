# 医院中庭：现代日式夜景

分支 `codex/hospital-new-levels`，第 7 关，1280 × 768；第 8 关回到病房。仅本地开发，尚未发布。

## 视觉与空间

按现代日本医院庭院设计：排空的混凝土水池、湿混凝土步道、碎石种植地、低矮修剪灌木、黑松、长椅与一辆空轮椅。北侧医院立面保留重复暗窗和少量亮窗。温室以冷色磨砂玻璃和细框架表达；灯具为现代冷白灯，入口侧略暖。使用稀疏构图与长视线制造空旷感。

树木采用 image_gen 生成的透明黑松素材，源图和无损 WebP 均保存于 `public/assets/garden-pine-v1.*`，来源记录在 `game/assets/garden-pine-source.json`。代码绘制混凝土、水池、道路、玻璃、灯具、灌木及雨痕。月光保留暗部方向感；低植被使用软阴影。

## 搜寻与事件

门卫室放铜钥匙，温室放无锁箱，养护区放铜锁箱，东北工具房单门上锁，里面是最终箱。候选物品位置按房间随机。

水池北、南两条路线均可通行。取得无锁箱后走入北步道，五盏路灯依次变暗，短暂停留后依次恢复。出口灯始终保留；事件不改变碰撞。最后保险丝取得后取消尚未完成的灯光事件并恢复基础照明。音乐和短音效复用既有库，本轮未生成户外环境音。

## 2026-09-08 氛围修订

- 中庭全局月光改为低强度暗红光（0.12）；路灯强度系数由 0.82 调整为 0.58，范围系数由 0.8 调整为 0.68，仅影响中庭。
- 排空水池底部保留雨水，加入随时间轻微错动的像素血月倒影。路灯、手电仍保留原有颜色。
- 地面补充不规则积水、路缝苔痕、长椅和花坛边的落叶堆、湿脚印。室内污迹数量按地图面积缩放，补充墙脚渗水和设备拖痕。
- 浏览器截图检查使用独立渲染场景，关闭照明的地图全景只用于查看污迹分布，不代表游玩亮度。前 3 关全景与中庭实际照明画面已检查；本次没有重新进行完整通关平衡测试。

## 血月事件

第一枚保险丝取得后回到 NorthPathZone，先触发既有路灯熄灭序列；9 秒后开始 3 秒渐变。月光、路灯、手电、出口和局部光源统一转红，灯具发光面同步变色。保留光源范围，降低照明强度及红色叠加强度；移除水池旁的人造红色光源，事件期间显著减弱全局月光。路灯和手电以低频、不等间隔的短暂衰减制造失光感，暗处不被染成发光红雾。血月状态在最后一枚保险丝取得后继续保留，直到结算或重新开局；暂停冻结渐变。新增事件时序测试及浏览器实际红色像素、重开恢复检查。
